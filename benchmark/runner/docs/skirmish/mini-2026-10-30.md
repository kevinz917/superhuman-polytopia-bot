# mini-SWE-agent Polytopia pilot — 2026-10-30

One independent authoring attempt per model and track. These are integration-pilot results, not a statistically reliable ranking of the underlying models. All calls use OpenRouter.

- Harness: mini-SWE-agent 2.4.6, upstream DefaultAgent/OpenRouterModel with a Modal bash adapter.
- Models: `deepseek/deepseek-v4-flash-0731` and `openai/gpt-6-luna`; both use high reasoning and 32,768 maximum output tokens/call.
- One-shot: one 1,200-second coding window, no expert-game feedback.
- Revision: initial 300 seconds plus three 300-second coding revisions. After each of the first three stages, six full public traces are supplied (drylands/lakes/continents, both seats). Evaluation is outside coding time.
- Offline isolated sandbox: two CPU cores, 2 GiB, Rust 1.90, std/serde_json 1.0.145, complete Markdown rule book.
- Fixed expert: released `hero-1v1`, checkpoint SHA `e6f4e1977e7f9cdcfbbe17358d87e49d638d82150496a6d4099e0cd389b0934f`.
- Existing Rust engine: `polytopia-2.17.3`, Bardur 1v1, 14×14. Guest: 256 MiB, one trillion fuel/game, two-second decisions plus five-second startup. Referee: 180 seconds, 100 rounds, 10,000 actions. Forfeits and unresolved games are reported separately.

## Verification and artifacts

- Targeted Modal checks: 33 passed, one skipped (the rule-book generator is operator tooling outside the runtime image). The generated Markdown was separately checked against its source files locally.
- Live sandbox preflight passed: unprivileged offline compilation, protected trusted-build directory, background-job cutoff, pristine frozen-source compilation. Both API models also passed short pipeline smoke tests.
- A prior integration cohort exposed a missing tool-result receipt after an early submission. The affected trial was excluded as an infrastructure failure, not scored as a model loss. The corrected v2 adapter passed a live OpenRouter early-submit/resume probe. Further calibration exposed a cumulative fuel ceiling and output truncation. This report uses a fresh v3 cohort with the calibrated runtime and explicit larger response allowance.
- Full sources, Wasm, model trajectories, feedback JSONL, trusted private action chains, source archive, package versions and receipts remain in Modal staging volume `polytopia-skirmish`.
- Run prefix: `mini-20261030c`; roots: `mini-runs/<run-id>` and `mini-tournaments/<tournament-id>`.
- The adjacent JSON is a compact read-only export. It contains no generated bot source, checkpoint or full trace.

Limitations: one authoring run per cell and one map per family are too small for robust model rankings or causal claims about feedback. The two tracks share a maximum 20 coding minutes, but models can submit early and differ in API latency. High reasoning, document-reading cost and context-management behavior are part of this fixed harness. These neutral prompts do not test psychological pressure.
