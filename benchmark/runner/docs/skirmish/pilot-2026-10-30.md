# Polytopia Skirmish: implementation and first pilot (2026-10-30)

**Updated ranking:** see [the corrected same-bot reevaluation](results-review-2026-10-30.md). The historical ranking below includes a restrictive runner fuel allowance.

This is a working coding benchmark inside the existing private repository, on
`codex/polytopia-skirmish`. The first implementation is commit `0115146`.
See [the protocol and commands](../../skirmish/README.md).

## What runs

A trusted controller gives a model five tools: read reference files, replace Rust
source, compile offline, play a practice campaign, and review its public traces.
Compilation runs in a separate Modal sandbox with networking blocked, no model
credentials and no checkpoint files. Generated Rust compiles to WASI WebAssembly;
the game runner provides only stdin/stdout, 256 MiB memory, a fixed fuel budget
and decision deadlines. The referee is the existing Rust engine through
`RustEnvironment`, not a new rules implementation. The first track is Bardur,
14×14 classic maps, two seats, `polytopia-2.17.3`.

Every submission retains source, Wasm, build lockfile, complete API/tool
transcript, prompt, protocol, source archive and hashes on Modal staging's new
`polytopia-skirmish` volume. Final maps are selected only after submissions freeze.
The round robin plays every pair in both seats on the same maps. Reference
`hero-1v1` is pinned by checkpoint SHA-256, runs deterministically, and anchors
Bradley–Terry Elo at zero. It is the strongest released raw 1v1 policy in the
inspected qualification report; its strength against every search configuration
has not been established by this pilot.

Both trials received 300 seconds, the same prompt, starter, tool schema and
resource limits. OpenRouter was the only model API used. Neither model had
internet tools or access to the trusted controller's network/filesystem.

## Separate held-out reference checks

Each frozen bot played four fresh maps in both seats. Both scored **0 wins / 8
losses**, with zero runtime forfeits or unresolved games. These were independent
map allocations, so the combined round robin is the common-map comparison.

## Validation and interpretation

- All **21 targeted tests passed on Modal**, including provider tool-call
  transcripts, paired schedules, Elo/failure accounting, deadline boundaries,
  WASI capabilities and fuel exhaustion. Local pure-metadata checks also passed;
  compilation, simulation, inference and replay verification ran on Modal.
- Live sandbox probes confirmed blocked outbound TCP, no reference mount and no
  `OPENROUTER_API_KEY`. The starter compiled offline and completed both seats
  against the pinned reference.
- Runtime faults are forfeits, separate from native defeats. Engine truncations
  and referee wall-clock cutoffs stay unresolved and do not enter the Elo fit.
- This is one short writing run per model. It validates the feedback loop, not a
  dependable model ranking. Four-map bootstrap intervals are conditional on
  these frozen bots and collapse for all-win/all-loss samples; they must not be
  read as evidence of precise strength. Elo is regularized and roster-relative.
- OpenRouter adapters were exercised live with these two models. Responses and
  Anthropic adapters have protocol tests but have not had live model trials.

The default configuration at `configs/skirmish/default.json` allows one hour of
writing and 32 held-out maps. The pilot configurations intentionally use five
minutes and four held-out maps. No one-hour run was launched.

## Completed common-map round robin

Four new maps, both seats, all three pairings: **24/24 games resolved**.
[Machine-readable report](pilot-2026-10-30-ladder.json).

| Frozen entrant | Wins–losses | Elo (hero = 0) | Runtime forfeits |
|---|---:|---:|---:|
| hero-1v1 | 16–0 | 0 | 0 |
| GPT-5.6 Terra | 5–11 | −572 | 0 |
| DeepSeek V4 Flash 0731 | 3–13 | −651 | 5 |

GPT's bot won the head-to-head 5–3, **but all five wins were guest exits/fuel
exhaustion by DeepSeek**, not native strategic victories. DeepSeek won the three
head-to-head games that resolved natively. This is a practical reliability result,
not evidence that GPT's strategy was stronger. The separate reference matches did
not reveal this failure mode because the reference won those games earlier.
The runtime limit and diagnostic cause must be reviewed before interpreting a
larger ladder or a prompt-pressure study.

The two separate eight-game evaluations were replay-verified: 2,351 actions for
DeepSeek and 2,266 for GPT. The combined round robin also passed replay verification: **7,820 actions**. Across the three evaluations, all **40 games and 12,437 actions** replayed correctly; see [audit receipts](pilot-2026-10-30-audits.json).

A calibration replay of the same first head-to-head game with 100 billion fuel instead of 2 billion completed natively: DeepSeek won by elimination on turn 26 after 648 actions, with no guest errors. This is a runtime calibration, not a new competitive ladder result.
