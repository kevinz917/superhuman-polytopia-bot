# Ablation arms, pre-registered (2026-10-20, before launch)

Program: [next-run-and-strength-2026-10-20.md](../next-run-and-strength-2026-10-20.md), Stage 2. Ledger
`runs/ablation-v1/budget.json` (cap $200). Parent for every arm: c3 u4854. Board 14×14, map mix `proposed-v1`,
1×H100 learner + 12 × 16-vCPU actor containers (24 games per process), 3,600 s of training each, launched together.

Control = c3's own recipe: lr 2e-4, entropy 0.005, 3 epochs, batch 262,144, minibatch 16,384, segment 32, γ 0.995,
λ 0.99, per-decision clock, critic bootstrap at the cap, 5% games vs frozen c3, 15% vs the run's own snapshots
(every 50 updates, last 8). Each arm changes exactly one thing against that:

| Arm | run id | Change | Seed |
|---|---|---|---|
| 0 | `abl-control` | none | 101 |
| 1 | `abl-capscore` | `cap_score_reward 0.5`: a game at the round cap ends ±0.5 for the seat ahead on score (tie = 0) | 102 |
| 2 | `abl-omni` | `omniscient_critic`: separate critic on both seats' views, 60 critic-only warm-up updates | 103 |
| 3 | `abl-pbrs` | zero-sum potential shaping, coef 0.3 over stars/units/territory/cities, scale annealed to 0 at update 500 | 104 |
| 4 | `abl-filter` | 1 epoch, top-25% |advantage| per batch, EMA 0.999 deployed (Generals.io recipe) | 105 |

Learner precision: whatever `docs/ablation-v1/precision-gate-2026-10-20.md` recommends, the same for all arms.

Readouts, fixed in advance:
1. Training-time record vs frozen c3 (sampled both sides), per 50 updates, from each run's `training.json`.
2. Final ladder: every arm's deployed `final.npz` vs c3, deterministic both sides, frozen engine, 128 fresh
   `proposed-v1` 14×14 maps × 2 seats (seeds 371300–371427, unused so far), one `select` call so every arm plays
   the same boards. Arm 4 is also compared at equal sample count (its update-N snapshot where N·65,536 ≈ the
   control's samples) besides equal wall-clock.
3. Pass for an arm: ≥ 58% of games vs c3 with the 95% CI above 50%, and ≥ 5 points above the control on the same
   maps. Differences under 5 points are noise (one seed per arm). The control's own result says whether c3 still
   improves with more compute at all.
4. Side metrics per arm: turn-cap rate and mean game length in the ladder, recruit mix, critic value std and
   explained variance, policy entropy, samples/s.

Smoke before launch: `abl-smoke-all` (all four changes on at once, 7 min, 2 actor containers) must run to the end
with no actor error, finite metrics, `kept` = 25% of the batch, and cap-score results counted.

Launch log: all five arms launched 13:28 PDT with `POLYTOPIA_MATMUL_PRECISION=DEFAULT POLYTOPIA_HEAD_PRECISION=HIGHEST`
on the learner. Modal preempted the learner containers of arms 2 and 3 at ~updates 13 and 24; the automatic
restart died on the run folder (fixed: the learner now tolerates an existing folder). Both relaunched unchanged as
`abl-omni-2` and `abl-pbrs-2` at 13:50 PDT, so they finish ~22 min after the other three; the ladder waits for them.
