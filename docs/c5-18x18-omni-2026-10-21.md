# 18×18 omniscient critic + turn clock from grown c3 (c5 arm D, 2026-10-21)

Arm `c5-l18-omni`, the 18×18 run the ablation readout recommended
([readout](ablation-v1/readout-2026-10-20.md), [long-horizon credit](long-horizon-credit-2026-10-20.md)):
the omniscient critic that made c3 learn again on 14×14, plus the turn-clock credit that fixed the 18×18 critic,

  extra actors were attached; 9.3k in the last window after the refill.

## Fixes before the next distributed run

1. `orchestrate` is replayed by Modal after a preemption and re-spawns the fleet: make it idempotent (exit if
   `registry[run_id]` is live and younger than the hard timeout), or spawn the learner and actors from the
   local entrypoint with `--detach`.
2. The learner's `finally` marks the shared registry key `stopped` whoever owns it; it should only do so when the
   entry still carries its own host/port, and actors should compare the address they connected to.
3. Evaluation entrypoints (`select`, `final_eval`, `arena`) should run detached; the local client must not be a
   single point of failure for a $2–5 match.
