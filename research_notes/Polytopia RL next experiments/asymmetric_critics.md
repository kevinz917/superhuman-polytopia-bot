# Asymmetric / omniscient / centralized critics and oracle guidance for RL in hidden-information games

Scope note: findings below come from primary sources where possible (arXiv/ar5iv full text, Nature PDF mirror, PMLR pages). Year and peer-review status are given per item. "Privileged critic" = value function that sees information the policy cannot (opponent's view, full state, hidden hands). Numbers are quoted from the papers; where only figures (no text numbers) exist this is flagged.

## 1. AlphaStar (Vinyals et al., Nature 2019): how the value function used the opponent's observations, and the ablation

### Takeaway
AlphaStar's value functions took the opponent's observations as extra input (training only), explicitly "to decrease the variance of the value estimates"; the paper's RL ablation (Fig. 3k) shows a best-response win rate of 22% without opponent info vs 82% with it, the single largest effect among the RL ablations. The baseline also kept the policy's own LSTM output as input (i.e., it is a history+privileged critic, not state-only).

### Cited Findings
- Methods, "Value and policy updates": "To decrease the variance of the value estimates, we also use the opponent's observations as input to the value functions (ablation in Fig. 3k). Note that these are used only during training, as value functions are unnecessary during evaluation." — [Vinyals et al. 2019, Nature (peer reviewed), PDF mirror](https://gwern.net/doc/reinforcement-learning/model-free/alphastar/2019-vinyals.pdf); DOI page [nature.com](https://www.nature.com/articles/s41586-019-1724-z)
- Fig. 3k "Value function" ablation (avg. win rate of a best response trained against fixed opponents, simplified setup: one map, PvP, 10^10 steps): "Without opponent info 22%", "With opponent info 82%". Fig. 3i (off-policy learning, same metric): "V-Trace 49%, + TD(λ) 73%, + UPGO 82%". Caption: "i, k, Reinforcement learning ablations, measured by training a best response against fixed opponents to avoid multi-agent dynamics." Fixed opponents = "a uniform mixed strategy composed of the first ten league exploiter Protoss agents". — [same PDF](https://gwern.net/doc/reinforcement-learning/model-free/alphastar/2019-vinyals.pdf)
- Critic form and training: "a value function Vθ(st, z) is trained to predict rt" (terminal reward ±1/0, no discount); "separate value functions and losses are computed for each pseudo-reward" (build-order edit distance, cumulative-stat Hamming distance; each pseudo-reward active with probability 25%); hybrid off-policy: "off-policy corrections for the policy (which avoids instability), with an uncorrected update of the value function (which introduces bias but reduces variance). Specifically, the policy is updated using V-trace and the value estimates are updated using TD(λ)"; UPGO uses a one-step action value "Q(st, at, z) = rt + Vθ(st+1, z)". Overall loss = weighted sum of policy + value losses (win-loss and pseudo-rewards) + KL to supervised policy + entropy; Adam. 139M weights total, 55M needed at inference (the rest is training-only, incl. value heads). — [same PDF](https://gwern.net/doc/reinforcement-learning/model-free/alphastar/2019-vinyals.pdf)
- Discussion: "The use of an opponent's observations for a lower-variance baseline and new components, such as hybrid off-policy learning, UPGO, and distillation towards an imitation policy, are also widely applicable." — [same PDF](https://gwern.net/doc/reinforcement-learning/model-free/alphastar/2019-vinyals.pdf)
- Baseline inputs per the community re-implementation of the Supplementary "Detailed Architecture" (mini-AlphaStar, secondary source): `Baseline.forward(lstm_output, various_observations, opponent_observations)`; the opponent's observations (agent statistics, upgrades, unit-count bag-of-words, units/buildings, effects, beginning build order, cumulative score) "go through the same pre_forward method, so they share weights with the player's embedding"; concat [lstm_output, own embedding, opponent embedding] → linear 256 → 16 ResBlocks (256, layernorm) → linear 1 → `(2/π)·atan((π/2)·x)`; one such baseline per reward type (`winloss`, `build_order`, `built_units`, `effects`, `upgrades`). — [mini-AlphaStar baseline.py](https://raw.githubusercontent.com/liuruoze/mini-AlphaStar/main/alphastarmini/core/arch/baseline.py) (2021, not peer reviewed; reimplementation)
- OpenAI's description of it: "AlphaStar's value network observed full information about the game state (including observations hidden from the policy); this method improved their training and exploring its application to Dota 2 is a promising direction for future work." — [Berner et al. 2019, arXiv:1912.06680](https://arxiv.org/abs/1912.06680) (not peer reviewed)
- AlphaStar Unplugged (offline RL on SC2, 2023, not peer reviewed) does NOT report using opponent observations in its critic; its value head is an MLP on the shared vector features, and its one critic-related finding is that a fixed behavior-value critic V^μ was more stable than a learned V^π in offline actor-critic: "although the win rate first increases in both cases, it stays high with V^μ but deteriorates with V^π". — [Mathieu et al. 2023, arXiv:2308.03526](https://arxiv.org/abs/2308.03526)

### Inferences
- The AlphaStar critic is of the "history + privileged" form (policy LSTM state + own stats + opponent stats), which is exactly the form later theory (Baisero & Amato 2022; Lyu et al. 2022) shows is unbiased, unlike a state-only critic. The opponent info is a compact summary (unit counts, upgrades, build order, score), not the opponent's full raw observation.
- The 22% → 82% effect was measured in a best-response setting against fixed opponents, which isolates the critic effect from league dynamics; it is a win-rate-at-fixed-compute number (10^10 steps), i.e., primarily a sample-efficiency / variance effect, not necessarily a final-asymptote effect.
- No warm-up / drop schedule: the privileged inputs were used throughout RL and simply discarded at inference (value heads are not part of the 55M inference weights).

### Gaps
- The exact list of opponent features in the official Supplementary "detailed-architecture.txt" could not be fetched (Nature supplementary zip is behind the publisher's site); the mini-AlphaStar reconstruction is used as proxy.
- No Elo-level ablation of opponent info in the full league is reported; only the simplified best-response win rate.

## 2. Asymmetric actor-critic (Pinto et al. 2017) and OpenAI Dactyl / Rubik's Cube (2018/2019): design and reported benefit

### Takeaway
Pinto et al. introduced the state-only critic (critic sees full simulator state, actor sees images) with DDPG+HER and showed large gains over symmetric critics on sparse-reward tasks; OpenAI's Dactyl and Rubik's Cube used a privileged, noise-free value network with the same architecture as the policy (incl. its own LSTM, so it has history), but published no ablation of the critic's benefit.

### Cited Findings
- Pinto et al. 2017 (arXiv, later RSS 2018): "the critic on full states while the actor (or policy) gets rendered images as input"; critic inputs are the full state s_t, goal state g and action a_t only — the critic does NOT receive the image observation; actor gets RGBD images (goal image in multi-goal). Trained with DDPG and HER from a shared replay buffer. — [arXiv:1710.06542](https://arxiv.org/abs/1710.06542)
- Results are figure-only (mean over 5 seeds): on Particle, asymmetric DDPG and HER "clearly outperform their symmetric counterparts"; on Fetch Pick (hard sparse reward) asymmetric HER "significantly outperforms symmetric HER". Real-robot Table I (5 trials each): asymmetric HER 5/5 on Pick, Forward Push, Block Move; symmetric HER, asymmetric DDPG and vanilla BC 0/5 on the main tasks; DAgger 3/5 on Pick. A "bottleneck" auxiliary loss (actor layer predicts full state, L2) improved stability/speed and reduced variance. — [arXiv:1710.06542](https://arxiv.org/abs/1710.06542)
- Baisero & Amato's critique: Pinto et al.'s evaluations were "effectively fully observable reactive tasks" so they do not establish performance under strong partial observability. — [arXiv:2105.11674](https://arxiv.org/abs/2105.11674)
- Dactyl (OpenAI 2018, arXiv; not peer reviewed): "the value network can have access to information that is not available on the real robot system"; Table 2 value-only inputs: object orientation, target orientation, hand joint angles (24D) and velocities (24D), object velocity and angular velocity; shared with policy: fingertip positions, object position, relative target orientation. "The observation noise is only applied to the policy inputs and not to the value network inputs." "Both networks have the same architecture but have independent parameters" (input norm → FC ReLU 1024 → LSTM 512); "There is no weight sharing between the two networks." Hypothesised benefit only: it "potentially simplifies the problem of learning good value estimates since less information needs to be inferred." No asymmetric-vs-symmetric ablation (only LSTM vs FF value function). PPO hyperparameters (Table 10): γ=0.998, GAE λ=0.95, entropy 0.01, clip 0.2, Adam lr 3e-4, batch 800k transitions/GPU, minibatch 25.6k, 60 minibatches/step. — [arXiv:1808.00177](https://arxiv.org/abs/1808.00177)
- Rubik's Cube (OpenAI 2019, arXiv; not peer reviewed), Sec. 6.2 "asymmetric actor-critic": policy and value separate but same architecture; value gets noise-free copies of all policy inputs plus hand joint angles (48D), full sim positions qpos (170D) and velocities qvel (168D). Embed-and-add architecture (each input → 512-d embedding, summed, ReLU → FC 2048 → LSTM 1024; value head → scalar). No quantitative ablation of the asymmetric critic. — [arXiv:1910.07113](https://arxiv.org/abs/1910.07113)
- Non-game but directly measured: "Privileged Critic Training Enables Sensor-Free Thruster Fault Adaptation" (2026, arXiv, not peer reviewed): PPO critic = task observation + 16-d true degradation state; actor sees only the 15-d observation. At k=4 simultaneous failures: no privileged critic 4.8% success; memoryless MLP actor + privileged critic 66.4%; GRU actor + privileged critic 70.2%; oracle actor 82.4%; recurrent actors without privileged critic ≤4.0%. Hyperparameters: 5,000 PPO iterations, 4,096 envs, 24-step rollouts, Adam 3e-4, 5 epochs, 8 minibatches. — [arXiv:2608.22976](https://arxiv.org/abs/2608.22976)

### Inferences
- OpenAI's robotics critics are "history + privileged" critics (same LSTM architecture as the policy, fed noise-free + extra state), not state-only; Pinto's is state-only. Both are recurring design points in later theory.
- Reported benefits in the robotics line are either figure-only (Pinto) or unmeasured (OpenAI); the thruster paper is the cleanest controlled PPO ablation (61-point jump from the critic alone).

### Gaps
- No ablation numbers exist for Dactyl/Rubik's asymmetric critic; none found in follow-up OpenAI reports either.

## 3. Baisero & Amato 2022 and follow-ups: when is a state-only critic biased, what is the unbiased form, and practical implications

### Takeaway
A state-only critic V(s) is in general ill-defined and biased for a history-conditioned policy in a POMDP; it is unbiased only when observations and states are in bijection and the policy is reactive ("an MDP in disguise"). The unbiased form is the history-state critic V(h,s)/Q(h,s,a) (history + privileged state, i.e., what AlphaStar and the OpenAI robotics critics approximately do); later work shows any state-dependent privileged signal i_t works if the critic also gets h_t, and that a state-only critic can also be higher-variance than a history critic.

### Cited Findings
- Theorem 4.1: the time-invariant state value V(s) of a non-reactive agent is generally ill-defined (depends on Pr(h|s), which is not a well-defined random variable). Theorem 4.2: even for reactive policies with state-only observation functions V(s) is generally biased: E_{s|h}[V(s)] ≠ V(h). Theorem 4.3: V(s) is unbiased only if observation/state are related by a bijection and the policy is reactive — "an unrealistic assumption"; "any POMDP which satisfies this assumption is really an MDP in disguise." — [Baisero & Amato, AAMAS 2022 (peer reviewed), arXiv:2105.11674](https://arxiv.org/abs/2105.11674)
- Unbiased form: history-state value V^π(h,s), Q(h,s,a) = R(s,a) + γE[V(hao, s')]; Theorem 5.1 E_{s|h}[V(h,s)] = V(h); Theorem 5.2 gives the unbiased asymmetric policy gradient with δ = R + γV(h',s') − V(h,s). Variance interpretation: "state-as-a-feature" (a stochastic realization of the belief); variance is low when beliefs are low-uncertainty. — [arXiv:2105.11674](https://arxiv.org/abs/2105.11674)
- Empirics (A2C variants, 20 runs each; Heaven-Hell-3/4, Shopping-5/6, Car-Flag, Cleaner, Memory-Four-Rooms): A2C-asym-s (state-only critic) "failed in several domains", converged slowly to suboptimal behavior in Shopping, "collapsed in Cleaner"; A2C-asym-hs (history-state) matched A2C in Cleaner/Memory-Four-Rooms, was "strictly better" in Shopping-5/6, and in Heaven-Hell-3/4 was "the only method capable of learning to solve the task at all". Fig. 4: the state critic gives identical values to histories sharing a state; the history-state critic assigns higher value after information gathering. Caveat from authors: when a problem "only deviates mildly from full observability" a state critic may still help in practice; A2C-asym-s was competitive in Car-Flag. — [arXiv:2105.11674](https://arxiv.org/abs/2105.11674)
- Asymmetric DQN (Baisero, Daley, Amato, UAI 2022, PMLR 180:107–117, peer reviewed): derives Asymmetric Policy Iteration (exact, model-based) then relaxes to Asymmetric DQN; trains a history-state value alongside a history Q-function; "Experiments in highly partially observable environments, which require both information gathering and memory, support the theoretical findings." — [PMLR page](https://proceedings.mlr.press/v180/baisero22a.html)
- Multi-agent version of the same analysis (Lyu, Baisero, Xiao, Amato, AAAI 2022, peer reviewed): state-based critic unbiased only if the state-averaged value equals the history value (e.g., observations deterministic functions of state + reactive policies); Dec-Tiger counterexample: history value ≈ 13.9 vs state values ≈ −16.2 ("a state value averages over all histories that visit that state, good and bad, so it can't reward information gathering"). Variance: even when unbiased, the state-based gradient variance is at least as large as the history-based one (Jensen on the belief). Recommendation: history-state critic (concat state + history). Empirics: history-state best on Dec-Tiger, Box Pushing, Cleaner; but "SMAC with COMA: state-based critics performed best overall in most scenarios, which the authors attribute to limited unit visibility and deterministic observations"; particle envs: state critics fine where observations are masked state. — [arXiv:2201.01221](https://arxiv.org/abs/2201.01221)
- JAIR 2023 extension (Lyu et al., peer reviewed): centralized and decentralized history critics have the same expected gradient (Thm 1); centralized history critic variance ≥ decentralized (Thm 2); state-critic bias "can be unbounded"; recommends history-state critics; notes that on broad benchmarks "performance gaps between critic types are often small, that some environments perform worse with centralized critics, and that many common benchmarks lack meaningful partial observability." — [arXiv:2408.14597](https://arxiv.org/abs/2408.14597)
- Theory for why asymmetric helps (Lambrechts, Ernst, Mahajan, ICML 2025, peer reviewed): with agent-state (recurrent) policies and linear critics, the symmetric critic's finite-time bound carries an extra aliasing term ε_alias (TV distance between the true belief given history and the belief given the agent state); the asymmetric critic Q(s,z,a) (state + agent state) "eliminates error terms arising from aliasing in the agent state"; trade-off: the asymmetric regression target can raise ε_grad. Purely theoretical, no experiments. — [arXiv:2501.19116](https://arxiv.org/abs/2501.19116)
- Informed Asymmetric Actor-Critic (Ebi, Ernst, Böhm, Lambrechts; arXiv 2025, listed as ICML 2026): critic V(h_t, i_t) may use any state-dependent privileged signal i_t (not necessarily full state) as long as it also conditions on the history; Theorem 3.1: gradient equals the standard policy gradient for any i_t, so signal choice affects variance/efficiency only. Synthetic study (10 runs): symmetric A2C AUC ≈1.06e5; full state ≈1.19e5; reward-relevant subset only ≈1.23e5 — full state was not the best signal. Recommendations: treat signal selection as a design choice; "Adding irrelevant or rapidly varying features can hurt value estimation, even with high-capacity networks"; screen signals with a residual (conditional-independence) test pre-training and a prediction-gain test post-hoc. — [arXiv:2509.26000](https://arxiv.org/abs/2509.26000)
- Cai, Liu, Oikonomou, Zhang (NeurIPS 2024, peer reviewed): expert distillation can fail in general; it is poly-sample/poly-compute under a "deterministic filter condition"; a belief-weighted asymmetric actor-critic has polynomial sample complexity and quasi-polynomial compute on observable POMDPs; CTDE multi-agent extensions given. — [arXiv:2412.00985](https://arxiv.org/abs/2412.00985)

### Inferences
- Practical rule: always give the privileged critic the same history representation the policy uses (policy LSTM state or stacked observation history) plus the privileged features; never replace the history with the state. This matches what AlphaStar, Dactyl/Rubik's, Scaffolder, PerfectDou and Le Critique actually do.
- For a fog-of-war strategy game the bias condition is clearly violated (histories with the same hidden state differ in what the agent has scouted), so a state-only critic can actively punish information gathering (Dec-Tiger example); the history-state form is required rather than optional.
- Feed the critic a compact, reward-relevant summary of hidden information (opponent unit counts, tech, economy, positions) rather than the opponent's entire raw observation; the Informed-AAC synthetic result suggests full state can be worse than a relevant subset.

### Gaps
- Baisero & Amato report returns only in figures; no numeric effect sizes in the text.
- No paper quantifies the "extra variance" of the history-state critic relative to a plain history critic in a large game; AlphaStar's 22→82% suggests the net effect is strongly positive in practice.

## 4. Suphx oracle guiding, DouZero/PerfectDou and other perfect-information distillation results: schedules and magnitude of gain

### Takeaway
Suphx fades privileged features out of the policy input with a Bernoulli dropout mask whose keep-probability γ_t decays 1→0, then continues training with lr/10 and importance-weight rejection; it reports a gain (RL-2 > RL-1) but only as box plots. PerfectDou shows that putting the perfect information only in the critic (PTIE) beats DouZero with ~10× fewer samples; its ablation shows perfect-info critic > imperfect-info critic by ~1.5 WP points / 0.09 ADP vs DouZero, and that the oracle-based reward shaping mattered more for ADP than the critic input. Plain distillation from an oracle policy is reported to work poorly (Suphx; Boney et al.).

### Cited Findings
- Suphx (Li et al. 2020, arXiv; not peer reviewed). Oracle sees (1) own private tiles, (2) all discards, (3) public info (scores, Riichi bets), (4) other three players' private tiles, (5) wall tiles; normal agent sees (1)–(3). "simple knowledge distillation does not work well: it is difficult for a normal agent, who only has limited information access, to mimic the behavior of a well-trained oracle agent". Schedule: policy input [x_n(s), δ_t x_o(s)] with δ_t a Bernoulli dropout matrix, P(δ_t(i,j)=1)=γ_t, "We gradually decay γ_t from 1 to 0." After γ_t=0: "continue the training of the normal agent for a certain number of iterations... First, we decay the learning rate to one tenth. Second, we reject some state-action pairs if the importance weight is larger than a pre-defined threshold... without these tricks, the continual training is not stable and does not lead to further improvements." Decay function, iteration counts and threshold are NOT given. Each RL agent: 1.5M games, 44 GPUs, 2 days; only the discard model is RL-trained. Result: "RL-basic leads to good improvement over SL, RL-1 outperforms RL-basic, and RL-2 brings additional gains against RL-1" (Fig. 8 stable-rank box plots over 1M games vs 3 SL-weak agents; no numbers in text). Future work explicitly suggests "an oracle critic" providing instant feedback from perfect information, and reports that simultaneous oracle+normal training with distance constraints "also works quite well" in preliminary experiments. — [arXiv:2003.13590](https://arxiv.org/abs/2003.13590)
- PerfectDou (Guan et al., NeurIPS 2022, peer reviewed), "Perfect-Training-Imperfect-Execution": critic input = imperfect features + "additional perfect features": previous and next players' hand cards and their minimum play-out steps; actor = LSTM over imperfect features only. PPO+GAE, lr 3e-4, Adam, γ=1.0, λ=0.95, batch 1024, entropy 0.1; 880 CPU cores + 8 GPUs; action space abstracted 27,472→621. Oracle reward shaping from minimum play-out steps (scale 50), removed in a final fine-tuning stage. Tournament vs DouZero (10k decks): WP 0.543, ADP 0.143. Sample efficiency (100k decks): PerfectDou@1e9 steps vs DouZero@~1e9: WP 0.732/ADP 1.270; vs DouZero@~1e10: WP 0.524/ADP 0.014. Ablation table (1e9 steps, vs DouZero@~1e9 / vs DouZero@~1e10): PerfectDou 0.732/1.270 and 0.524/0.014; ImperfectDou (imperfect critic) 0.717/1.180 and 0.486/−0.057; RewardlessDou (perfect critic, no oracle reward) 0.738/0.490 and 0.540/−0.201; vanilla PPO 0.509/−0.307 and 0.346/−0.709. The paper contrasts itself with Suphx: "In Suphx, the perfect information is used by the actor and thus has to be dropped before the inference stage; on the contrary, PerfectDou feeds the critic with additional observations". — [arXiv:2203.16406](https://arxiv.org/abs/2203.16406)
- OADMCDou (IJCAI 2024, peer reviewed): oracle guiding (train an oracle with perfect info, gradually reduce reliance) + Deep Monte Carlo with gradient-weight clipping and update-magnitude limits; reports outperforming DouZero (performance 95% CI 0.104 ± 0.041; 28.6% loss reduction); schedule details not on the abstract page. — [ijcai.org/proceedings/2024/660](https://www.ijcai.org/proceedings/2024/660)
- Oracle-planner imitation (Boney et al. 2020, arXiv; not peer reviewed): full-state tree-search oracle, DAgger follower. Pommerman follower 23.3% win vs rule-based opponents (BC of the oracle 17.4%); Clash Royale follower beats Human-BC 71.4% but the oracle beats the follower 93.4% — the authors note oracle actions "may therefore be unachievable under partial observability" and that averaging oracle actions over hidden states is not optimal. — [arXiv:2012.12186](https://arxiv.org/abs/2012.12186)
- Theory of when distillation vs. RL wins ("To Distill or Decide?", 2025, arXiv): distillation success depends on approximate decodability; with deterministic latent dynamics error decays as (Cδ)^((h−1)/9); with stochastic (mixing) dynamics misspecification is Ω(min(1, δH)) and does not shrink with frame-stack length; asymmetric actor-critic–style methods are "fundamentally required" when distillation cannot encourage information-gathering actions. Empirically RL beat distillation at higher motor-noise levels (humanoid σ∈{0.1,0.2,0.3}, dog σ∈{0.2,0.3,0.4}). — [arXiv:2510.03207](https://arxiv.org/abs/2510.03207)

### Inferences
- Two distinct mechanisms exist: (a) privileged features in the policy that are annealed away (Suphx, OADMCDou) and (b) privileged features only in the critic (PerfectDou, AlphaStar). (b) needs no schedule and no inference-time change; (a) requires lr decay and importance-weight rejection to stay stable after the switch.
- PerfectDou's ablation suggests the critic-side perfect information is a modest but consistent gain (+1.5 WP points, +0.09 ADP) on top of a strong oracle-shaped reward; the oracle-derived dense reward mattered more for ADP (RewardlessDou ADP 0.49 vs 1.27).
- For a strategy game, the closest analogue of PerfectDou's "minimum play-out steps" shaping is a privileged progress signal (e.g., true relative army/economy) used in training-only reward shaping and then removed in a final fine-tune.

### Gaps
- Suphx gives no numeric γ_t schedule, iteration count, importance-weight threshold, or numeric stable-rank gain; Fig. 8 only.
- OADMCDou's schedule and metric definitions were not retrievable from the abstract page.

## 5. MAPPO / CTDE centralized critics (Yu et al. 2022): value-function inputs and what mattered

### Takeaway
MAPPO's SMAC ablation found that neither concatenated local observations (CL) nor the environment-provided global state (EP) alone were best; the agent-specific global state (AS = global state + the agent's own local observation) and its feature-pruned version (FP) worked best, i.e., the critic should contain both the agent's own view and global information, and dimensionality should be kept in check. Other factors (≤10 epochs, 1 minibatch, clip ≤0.2, value normalization, death masking) were as important as the critic input.

### Cited Findings
- Value inputs: CL "ineffective, particularly in maps with many agents"; EP "notably achieves subpar performance in more difficult maps" (lacks local, agent-specific info). Median win rates at 10M steps, AS vs FP: 3s5z_vs_3s6z 63.3 vs 84.4; 6h_vs_8z 85.9 vs 88.3; 27m_vs_30m 85.9 vs 93.8; 5m_vs_6m 88.3 vs 89.1; MMM2 87.5 vs 90.6; Corridor 98.4 vs 100.0. Recommendation: "include both local, agent-specific features and global features in the value function input" and check that they do not unnecessarily increase input dimension. — [Yu et al., NeurIPS 2022 Datasets & Benchmarks (peer reviewed), arXiv:2103.01955](https://arxiv.org/abs/2103.01955)
- Other suggestions with numbers: 15 PPO epochs "consistently learn a suboptimal policy" (MMM2, Corridor); use ≤10 epochs on hard tasks; 1 minibatch best on 22/23 SMAC maps, 4 minibatches solved none; clip ε=0.05 stable but slow, 0.2–0.5 "often result in sub-optimal performance", keep ε<0.2; value normalization "never hurts" and is critical in MPE Spread (returns from below −200 to 0); death masking (replace a dead agent's value input with a zero vector + agent ID) "significantly outperforms" alternatives and lowers value loss. Hanabi: local observation lacks the agent's own cards, so the critic is fed the global state. — [arXiv:2103.01955](https://arxiv.org/abs/2103.01955)
- TABX (2026, arXiv, not peer reviewed): "centralized value learning achieves substantially lower estimation error in scenarios that require global information" (clover, ribbon: enemies occluded early); but in crossfire/vsrangers "global information adds no structural advantage, and ... centralized critics can pick up irrelevant or redundant global features"; IPPO beat MAPPO on crossfire, vsrangers, ambush; value-estimation error vs return Pearson r = −0.82. — [arXiv:2602.01665](https://arxiv.org/abs/2602.01665)
- JAIR 2023 (Lyu et al.): centralized critics are not theoretically better in expectation for history critics and have higher variance; benefit arises only via the state (privileged) component, and only unbiased in history-state form. — [arXiv:2408.14597](https://arxiv.org/abs/2408.14597)

### Inferences
- MAPPO's "AS/FP" finding is the multi-agent version of the history-state rule: the centralized critic must include the acting agent's own observation, not just the global state.
- Global-state critics help in proportion to how much reward-relevant information is hidden (TABX); in fog-of-war 4X games, most of the opponent's economy/army is hidden for long stretches, which is the regime where TABX found the largest benefit.

### Gaps
- MAPPO gives no CL/EP numbers in text (figure only).

## 6. OpenAI Five: did the value function use hidden information?

### Takeaway
No. OpenAI Five's policy and value heads share one LSTM fed with human-visible observations; the paper explicitly lists AlphaStar's full-information value network as "a promising direction for future work" rather than something they did.

### Cited Findings
- Related work (Sec. 5): "AlphaStar's value network observed full information about the game state (including observations hidden from the policy); this method improved their training and exploring its application to Dota 2 is a promising direction for future work." Architecture: shared LSTM "feeds into separate fully connected layers producing policy and value function outputs" (Sec. 3.2); observations "approximate what a human player sees" (Sec. 3.1). Value loss weight 1.0 (Rerun), 0.25↔1.0 (OpenAI Five); team spirit annealed 0.3→1.0 (OpenAI Five), 0.3→0.8 (Rerun); rewards normalized by a running std estimate. Appendix M ablations cover batch size, staleness, sample reuse only. — [Berner et al. 2019, arXiv:1912.06680](https://arxiv.org/abs/1912.06680) (not peer reviewed)

### Inferences
- OpenAI Five is the main large-scale negative-by-omission data point: a shared-trunk, observation-only critic was sufficient to reach superhuman play in Dota 2 given ~10 months of compute, so a privileged critic is an efficiency lever, not a necessity.

### Gaps
- No OpenAI follow-up applying a privileged critic to Dota was found.

## 7. Privileged critics in turn-based strategy / 4X / wargames; negative results

### Takeaway
I found no peer-reviewed work applying a privileged critic to a 4X/turn-based strategy game; the closest are MOBA (Honor of Kings, which did use invisible-opponent features in the value net and reports an Elo gain in a figure), StarCraft: Brood War (full state as an auxiliary prediction target), an RLaR actor-critic in MicroRTS, and a few negative/neutral results (state-only critics hurting in information-gathering POMDPs; centralized critics losing to IPPO on some maps; DeepNash not using one at all).

### Cited Findings
- Honor of Kings (Ye et al., NeurIPS 2020, peer reviewed): "we use full information about the game state, including observations hidden from the policy, as input to the value function"; "Note that this is performed only during training"; Table 5: 560-dim "Invisible information used for the value net"; plus multi-head value (farming, KDA, damage, pushing, win/lose). Sec. 4.2.3: "using invisible opponent information and multi-head value can both increase the Elo score effectively (Fig. 4-b)" vs OpenAI-Five-style value estimation (numbers only in the figure). Dual-clip PPO ε=0.2, c=3, γ=0.998, GAE λ=0.95, Adam lr 1e-4, minibatch 8192/GPU. — [arXiv:2011.12692](https://arxiv.org/abs/2011.12692)
- The earlier AAAI 2020 Honor of Kings paper (1v1) does not mention invisible info in the value net; policy and value share FC+LSTM; γ=0.997, λ=0.95, ε=0.2, c=3, lr 1e-4. — [arXiv:1912.09729](https://arxiv.org/abs/1912.09729)
- StarCraft: Brood War strategy selection (Gehring et al. 2018, AIIDE, peer reviewed): "investigate whether the full game state information can be utilized during training time (in the form of an auxiliary prediction task) to increase performance"; "encouraging results" from the auxiliary task; agents beat strong community bots. — [arXiv:1811.08568](https://arxiv.org/abs/1811.08568)
- RLaR ("reinforcement learning as a rehearsal"): "most suited in partially observable environments where the hidden/unobservable part of the state can be made available to an RL agent during training... but not when the learned policies are to be executed"; a DTIC project report applied RLaR to an actor-critic in MicroRTS. — [Knowledge Engineering Review preprint](https://maxapress.com/data/article/ker/preview/pdf/S0269888924000092.pdf); [DTIC AD1196764](https://apps.dtic.mil/sti/trecms/pdf/AD1196764.pdf)
- DeepNash / Stratego (Perolat et al., Science 2022, peer reviewed): critic v_θ(o_t) conditions only on the player's observation (own pieces, public info incl. a probability distribution over opponent piece types, recent moves); no privileged or centralized value function is described. — [arXiv:2206.15378](https://arxiv.org/abs/2206.15378)
- Negative/neutral results: state-only critics "failed in several domains" and "collapsed in Cleaner" (Baisero & Amato 2022) — [arXiv:2105.11674](https://arxiv.org/abs/2105.11674); IPPO outperformed MAPPO in 3 of TABX's scenarios where local info suffices — [arXiv:2602.01665](https://arxiv.org/abs/2602.01665); "some environments perform worse with centralized critics" (Lyu JAIR 2023) — [arXiv:2408.14597](https://arxiv.org/abs/2408.14597); fog-of-war chess student project (2026, not peer reviewed): folding a hidden-information signal into the training reward "degraded" the prior's tactical ranking, information-awareness worked better at inference — [CS224R report](https://cs224r.stanford.edu/projects/pdfs/Sandeep%20Sethuraman%20Kuba%20Hashemian%20Leon%20Junliang%20Liu%20submission_416267121/CS224R_Final.pdf)
- Pure privileged-expert imitation failures: A2D (Warrington et al., ICML 2021, peer reviewed): naive asymmetric imitation gets ≈−26.6 on Frozen Lake (optimal 4) and ≈−54 on Tiger Door (optimal 2) because "the expert has no knowledge of what the trainee does not know"; fix = refine the expert toward the trainee's implicit policy with policy-gradient steps (mixture weight β annealed aggressively or 0). — [arXiv:2012.15566](https://arxiv.org/abs/2012.15566)

### Inferences
- The absence of 4X-specific results means the practitioner must transfer from MOBA/RTS/card-game evidence; the common pattern across all positive results is "critic = policy's history representation + compact hidden-info summary" and "no change at inference".
- Negative results cluster around (i) state-only critics in tasks that need information gathering and (ii) pure distillation/imitation from an omniscient teacher; neither applies to a history+privileged critic.

### Gaps
- No Polytopia/Civilization/Lux-AI paper with a privileged critic was found; no negative result specifically for a history-state critic in any game was found.

## 8. Critic warm-up when the critic architecture changes, and learning the critic from both players' views in zero-sum self-play

### Takeaway
Several 2025–2026 systems freeze the actor and run value-only updates (≈20 updates/epochs) before resuming policy gradients when a new or re-initialized critic is introduced; AlphaStar Unplugged found a fixed behavior-value critic more stable than a freshly learned one. For symmetric zero-sum games the standard trick is one network applied to both seats via a perspective transform with sign-flipped outcomes; separate value heads per side are suggested when the sides are asymmetric. No paper quantifies the warm-up length needed for a privileged critic specifically.

### Cited Findings
- Le Critique (2026, arXiv, not peer reviewed; LLM RL): privileged critic V_φ(h, z) conditioned on the policy's own token history h plus privileged context z (ground-truth answer, solved grid, or other samples' rewards); "The value model is initialized as a copy of the base policy with a randomly initialized value head. In all experiments only 20 value updates are used before beginning policy optimization" (same rollout batch size); Monte Carlo targets (λ=1, binary-classification value loss); privileged critic beat the ordinary critic in all four tasks and explained more return variance; warns that conditioning on the trajectory's own future/feedback breaks unbiasedness, that "Too much extra context may hurt the critic's fit", and that "An early, weak value function can slow policy learning" (their Tether baseline starts at ρ=0 to mitigate this). — [arXiv:2608.16739](https://arxiv.org/abs/2608.16739)
- ADEPT (2026, arXiv, not peer reviewed): after BC, "The actor is frozen and only the critic updates for the first 20 post-BC epochs", then conservative PPO with lower actor lr and tighter clip. — [arXiv:2608.19182](https://arxiv.org/abs/2608.19182)
- Actor-critic pretraining for PPO (2026, arXiv): critic initialized from returns of the pretrained policy; sample-efficiency gain 86.1% vs no pretraining and 30.9% vs actor-only pretraining. — [arXiv:2602.23804](https://arxiv.org/abs/2602.23804)
- NeMo RL PPO has a built-in `policy_training_start_step` to train the value model for N steps before policy training. — [NVIDIA NeMo RL docs](https://docs.nvidia.com/nemo/rl/latest/guides/ppo.html)
- AlphaStar Unplugged (2023): offline actor-critic with a fixed V^μ critic kept the win rate high, whereas a learned V^π "deteriorates" and the V-trace importance ratio "decayed much faster and lower when using V^π". — [arXiv:2308.03526](https://arxiv.org/abs/2308.03526)
- Symmetric self-play: "For symmetric zero-sum games, where r_i(s) = -r_j(s), we can assume that each player uses the same policy, modulo rearrangement of the input state" (e.g., swapping sides' piece vectors in chess). — [Murphy, RL: An Overview, arXiv:2412.05265](https://arxiv.org/abs/2412.05265); lemma that both players' expected returns match under a shared policy with a symmetric start distribution — [Best Response Shaping, arXiv:2404.06519](https://arxiv.org/abs/2404.06519); for asymmetric sides (Tablut) a student report uses a shared trunk with separate attacker/defender policy and value heads — [courses.cs.ut.ee](https://courses.cs.ut.ee/student_projects/download/994.pdf) (not peer reviewed)
- AlphaStar trained one value head per reward type and used the opponent's observations symmetrically (same embedding weights for own and opponent stats) — [mini-AlphaStar baseline.py](https://raw.githubusercontent.com/liuruoze/mini-AlphaStar/main/alphastarmini/core/arch/baseline.py); Honor of Kings used per-camp training data with 560-d invisible-opponent features — [arXiv:2011.12692](https://arxiv.org/abs/2011.12692)

### Inferences
- When switching to a privileged critic mid-run (new input embedding for hidden features), the consistent practice is: keep the policy frozen, run ~20 value-only updates (or until explained variance recovers), then resume PPO with a reduced actor lr/clip; AlphaStar Unplugged's result suggests a stale-but-consistent critic beats a rapidly drifting one, so a short warm-up with a conservative actor is safer than none.
- In symmetric self-play, train the privileged critic on both seats' trajectories with a perspective transform (own vs opponent feature slots swapped, outcome sign flipped); this doubles critic data per game and, because the opponent's features are the privileged part, each game provides both "my view + their hidden info" and "their view + my hidden info" samples. Use shared embedding weights for own/opponent stat encoders (as mini-AlphaStar does) so the transform is exact.

### Gaps
- No paper reports a warm-up schedule specifically for swapping a symmetric critic for a privileged one mid-training; the 20-update/20-epoch figures come from LLM RL and robotics BC→RL settings.
- No quantitative source on the benefit of training a zero-sum critic from both perspectives.

## 9. Extensions beyond a plain privileged critic: belief-state critics, auxiliary hidden-state prediction, privileged distillation, world-model scaffolding

### Takeaway
The strongest documented extensions are (i) auxiliary prediction of a privileged belief/hidden state from the policy's history features (BGN: 0.22→1.00 normalized return on Hallway-2), (ii) routing privileged info through the critic, world model, reward model and exploration policy simultaneously (Scaffolder: closes ~79% of the privileged-vs-blind gap, with the critic the most important component in some tasks), and (iii) adaptive imitation of a privileged expert with a divergence-constrained weight (COSIL, A2D) rather than fixed distillation. Belief-conditioned critics (Ah-Cb) underperform history critics with belief auxiliary losses.

### Cited Findings
- Belief-Grounded Networks (Nguyen et al., CoRL 2020, peer reviewed): A2C with GRU actor and critic over observation-action histories; each network has an extra softmax head trained with cross-entropy to the simulator's true belief (training only). Normalized returns (1.0 = SARSOP): Ah-Ch+BGN Hallway 1.02, Hallway-2 1.00, RockSample[4,4] 0.95, [5,5] 0.94; Ah-Ch (no BGN) 0.94, 0.22, 0.88, 0.84; Ah-Cs (history actor, state critic) 0.85, 0.72, 0.86, 0.84; Ah-Cb (belief critic) 0.90, 0.81, 0.85, 0.84; Ab-Cb (belief policy) 1.00, 1.03, 0.95, 0.95. Physical robot: 100% success on three tasks without fine-tuning. — [arXiv:2010.09170](https://arxiv.org/abs/2010.09170)
- Mutual-information asymmetric learning (Nguyen et al., CoRL 2024 / PMLR 270, peer reviewed): uses state–observation and state–history mutual information (available in training) as intrinsic rewards and an auxiliary task to improve information seeking and memorization; reports outperforming strong baselines and sim-to-real transfer (numbers not retrieved). — [PMLR page](https://proceedings.mlr.press/v270/nguyen25b.html)
- Scaffolder (Hu et al., ICLR 2024, peer reviewed): privileged observations o⁺ used in (1) a scaffolded world model, (2) reward model, (3) critic v_ψ(s⁻, s⁺) — note the critic keeps the target recurrent state s⁻ because it "contains info about the historical beliefs of the agent", (4) a scaffolded exploration policy collecting data 1:1 with the target policy (no imitation loss), (5) an auxiliary decoder of o⁺ from the target latent. Bridges ≈79% of the o⁻/o⁺ gap on 10 tasks in 250K–5M steps; every ablation is worse than the full method; "The critic matters most for Blind Cube Rotation", exploration for Blind Pick, world model for Blind Locomotion; ~30–40% extra wall-clock vs DreamerV3; cautions against DreamerV3+BC when the privileged teacher's optimal behavior differs from what a blind student can do. — [arXiv:2405.14853](https://arxiv.org/abs/2405.14853)
- COSIL (Nguyen et al., CoRL 2022, peer reviewed): SAC with history critic Q(h,a); reward = task reward − α·D(μ(s), π(h)) against a fixed fully-observable expert μ(s); α adapted by gradient on α(D̄ − E[D]) with target divergence D̄ (grid-searched). Beat ADV-Off on Bumps-2D, Minigrid-Memory, Car-Flag; real-robot block picking 8/10 vs 6/10. Failure modes: "COSIL can bias exploration negatively if the state expert is heavily sub-optimal under partial observability"; on a modified Bumps-2D both COSIL and ADV-Off underperformed plain SAC; where the optimality gap is small, plain BC beat both. — [arXiv:2211.01991](https://arxiv.org/abs/2211.01991)
- A2D (Warrington et al., ICML 2021): fixes asymmetric DAgger by refining the privileged expert with importance-weighted policy-gradient steps on the trainee's implicit policy; β annealed aggressively or set to 0 worked best; reaches optimal POMDP reward on Frozen Lake/Tiger Door and avoids collisions in CARLA where AIL collides. — [arXiv:2012.15566](https://arxiv.org/abs/2012.15566)
- Oracle-critic idea stated as future work by Suphx: "we can consider designing an oracle critic, which provides more effective state-level instant feedback (instead of round-level feedback) to accelerate the training of the policy function based on the perfect information." — [arXiv:2003.13590](https://arxiv.org/abs/2003.13590)
- Agent-modeling auxiliary heads (Hernandez-Leal et al. 2019, AAMAS extended / arXiv): predicting the opponent's/teammate's policy as an auxiliary task "improves learning stability and increases rewards" in cooperative and competitive settings. — [arXiv:1907.09597](https://arxiv.org/abs/1907.09597)

### Inferences
- A combined recipe supported by the evidence: history+privileged critic (AlphaStar/PerfectDou) + auxiliary head on the policy trunk predicting a compact hidden-state summary (BGN/Gehring) + optional privileged reward shaping removed in a final fine-tune (PerfectDou). Avoid belief-only critics and avoid fixed-weight distillation from an omniscient policy.
- The Scaffolder ablation shows the privileged critic is the most important single channel in the task with the most hidden dynamics (Blind Cube Rotation), which is the closest analogue to deep fog of war.

### Gaps
- No work combines a privileged critic with an auxiliary hidden-state head in a two-player hidden-information game with a controlled ablation; the pieces are only validated separately.

## 10. Practical synthesis: recommended configuration and schedules (from the sources above)

### Takeaway
The configuration with the most support is: separate critic (or separate head) that receives the policy's own history embedding plus a compact, reward-relevant summary of hidden information; used from the start of RL (no annealing needed, nothing to drop); warm up the critic ~20 value-only updates when its inputs change; keep PPO conservative (≤10 epochs, 1 minibatch, clip ≤0.2, value normalization).

### Cited Findings
- AlphaStar: opponent observations in the value functions throughout RL, training-only, 22%→82% best-response win rate; TD(λ) uncorrected value updates. — [Vinyals et al. 2019](https://gwern.net/doc/reinforcement-learning/model-free/alphastar/2019-vinyals.pdf)
- PerfectDou: critic gets perfect features throughout; PPO lr 3e-4, γ=1.0, λ=0.95, batch 1024, entropy 0.1; oracle reward removed in final fine-tune. — [arXiv:2203.16406](https://arxiv.org/abs/2203.16406)
- Honor of Kings: 560-d invisible opponent features in value net; dual-clip ε=0.2, c=3; γ=0.998; λ=0.95; lr 1e-4; minibatch 8192/GPU. — [arXiv:2011.12692](https://arxiv.org/abs/2011.12692)
- Unbiasedness requires history + privileged signal in the critic; any state-dependent signal is admissible; irrelevant/rapidly varying privileged features can hurt. — [arXiv:2105.11674](https://arxiv.org/abs/2105.11674); [arXiv:2509.26000](https://arxiv.org/abs/2509.26000)
- Suphx annealing (if privileged features are put in the policy instead): Bernoulli keep-prob γ_t 1→0, then lr/10 and importance-weight rejection. — [arXiv:2003.13590](https://arxiv.org/abs/2003.13590)
- Critic warm-up ≈20 value-only updates/epochs before policy updates. — [arXiv:2608.16739](https://arxiv.org/abs/2608.16739); [arXiv:2608.19182](https://arxiv.org/abs/2608.19182)
- MAPPO hyperparameter guidance (epochs ≤10, 1 minibatch, clip <0.2, value normalization, death masking, agent-specific global state). — [arXiv:2103.01955](https://arxiv.org/abs/2103.01955)

### Inferences
- For a Polytopia-style fog-of-war self-play agent: (1) build the critic input as [policy trunk/LSTM output] ⊕ [own full summary] ⊕ [opponent hidden summary: true unit counts/positions, tech, stars/income, city count/levels]; (2) share the own/opponent summary encoders so the perspective swap is exact and train on both seats' trajectories; (3) when enabling the privileged critic on an existing run, freeze the actor for ~20 value updates, then resume with a reduced actor lr; (4) optionally add an auxiliary head on the policy trunk predicting the opponent summary (BGN/Gehring-style) and log its accuracy as a belief-quality metric; (5) measure with a fixed-opponent best-response win rate at fixed steps, as AlphaStar did, before judging league Elo.

### Gaps
- All schedule numbers (20 updates, lr/10) are borrowed from other domains; no paper tunes them for strategy games.
